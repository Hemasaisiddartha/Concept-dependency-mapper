# Frontend - Smart AI Concept Dependency Mapper

Interactive Web Application built with React, Vite, and HTML5 Canvas for the research study:
**"Improving Student Learning Outcomes Using Smart AI-Based Concept Dependency Mapper Compared to Traditional Learning Systems"**

## Features
- **Interactive Concept Graph Canvas**: High-performance DAG visualization with force layout, zoom/pan controls, dynamic mastery color coding (Mastered, Ready to Learn, In Progress, Locked, Needs Remediation), and curved dependency arrows.
- **Adaptive Pathway Generator**: Computes the shortest prerequisite subpath to master advanced target topics, skipping redundant linear content.
- **Student Dashboard**: Live progress tracking, ready-to-learn queue, and time-efficiency indicators.
- **Comparative Research Analytics**: Visual empirical study dashboard with 30-day retention decay curve, pre/post-test gains, and statistical effect size metrics ($d = 1.34$, $p < 0.001$).
- **Diagnostic Micro-Quiz Module**: Immediate knowledge gap diagnosis and mastery evaluation with congratulatory confetti and remediation hints.
- **AI Concept Tutor**: Interactive assistant for conceptual reasoning and prerequisite justifications.
- **Mobile Simulator**: Preview the smartphone experience directly in the browser.

## Running Locally
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.
